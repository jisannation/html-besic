Introduction to WordPress

What is WordPress?

WordPress is a free and open-source web publishing platform. It was originally created by Matt Mullenweg and Mike Little in 2003 as a fork of b2/cafelog. Today, it runs on PHP and pairs with MySQL or MariaDB databases.

WordPress allows users to build dynamic websites without deep coding knowledge, while also providing full extensibility for software engineers through custom APIs and hooks.

Code & Architecture

Developers can modify output using action hooks and filter hooks. For example, functions can be registered via code:

function custom_theme_setup() { add_theme_support('title-tag'); add_theme_support('post-thumbnails'); } add_action('after_setup_theme', 'custom_theme_setup');

Legacy widgets are now deprecated and replaced by Gutenberg block patterns.

Highlighted standard: Strict adherence to GPLv2 licensing ensures community freedom.

Ecosystem Overview

WordPress relies on distinct architectural pillars:

  1. Core Software: The foundational application files.
  2. Themes: The display presentation layer.
  3. Plugins: Addon modules that extend platform features.
  4. Database: Storage for posts, pages, options, and user tables.
